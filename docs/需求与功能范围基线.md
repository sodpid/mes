# MES 需求与功能范围基线

- 基线日期：2026-10-17；最近更新：2026-10-24；版本：V0.8。
- 用途：保存当前需求与方案范围，后续逐项对照实现、发现缺失遗漏并管理范围变化。
- 定位：面向通用离散制造，以 MES 为核心，覆盖采购、生产、销售、库存与质量。
- 本文记录业务范围，不代表代码已具备这些功能，也不代表所有方案建议均已获得用户确认。
- 初始记录时项目目录未发现已有业务代码；截至 2026-10-20 已形成需求基线及主数据详细设计，尚未开展业务代码实现审计，所有需求的实现核对状态仍为“未核对”。

## 1. 来源、阶段与核对方式

来源/确认状态：**用户明确**表示用户已直接提出；**方案建议**表示前述方案提出、尚需纳入正式范围确认；**待确认**表示仍有选择或边界未决。用户明确需求与建议细节分别记录，避免把建议视为承诺。

阶段：**一期建议**为基础闭环；**二期建议**为深化体验与效率；**三期按需**为扩展能力；**待定**为尚未确定纳入方式。阶段划分本身为方案建议。

实现核对状态可更新为：未核对、已实现、部分实现、未实现、不适用。更新时必须记录代码/接口/页面/测试或业务演示证据及日期；“未核对”不能直接当作“未实现”。

## 4. 关键流程与一致性规则

下列规则均为方案建议，实现核对状态均为“未核对”，建议用于一期验收。

| 编号 | 规则 | 核对要点 |
| --- | --- | --- |
| R-001 | 净需求按层计算 | 扣除可用库存、已有预留以及在途采购、在制、委外供应，考虑到货日期；不合格、冻结量不可作为可用供应 |
| R-002 | 避免重复需求与供应 | 订单冲减预测，备货按库存目标补足，建议转单可追踪；同笔产出仅形成一次供应/入库 |
| R-003 | 多层与在制计量 | 支持工序领料；半成品库存与在制明确区分，不重复计量；工序委外与在制不重复计量 |
| R-004 | 版本固定 | 生产订单固定 BOM、工艺、检验版本，后续资料修改不覆盖既有订单依据 |
| R-005 | 质量门禁 | 进货检控制领用，工序检控制受控下一工序，完工检控制成品入库，出库检控制实际发货；待检、不合格、冻结不可领用或发货 |
| R-006 | 库存过账 | 草稿不改库存，过账才改库存且须幂等；冲销、退货保留痕迹并检查下游影响 |
| R-007 | 委外资产 | 供应商处的我方材料/在制仍属我方资产，但不是厂内可直接领用库存；供料与产出核销可查 |
| R-008 | 组织与库存归属 | 组织数据与库存归属明确；跨公司业务不能作为普通调拨处理 |
| R-009 | 数量与状态 | 拆合单、分批、退货及异常处置均保持明细级关联；超量按已配置规则或审批控制 |

以下场景来源/确认状态为“方案建议”，实现核对状态为“未核对”。验收应保留单据、数量、质量状态、库存和追溯证据。

| 编号 | 场景 | 验收要点 |
| --- | --- | --- |
| A-001 | 订单机加工 | 销售需求→采购→进货检→生产/工序检→完工检→入库→出库检→发货，全链路关联与数量一致 |
| A-002 | 多层半成品备货后装配 | 半成品备货→订单需求→逐层净算→齐套装配→交付，验证共享半成品分配、预测冲减及防重复补货 |
| A-003 | 委外与质量异常 | 含工序委外、不合格、返工、复检后交付，验证供应商处资产与在制不重复计量 |
| A-004 | 委外类型覆盖检查 | 在既定委外范围内补充核对整单/物料委外，覆盖混合供料、分批收回与核销；与工序委外均有证据 |
