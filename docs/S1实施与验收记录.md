- Astra只读评审提出的审计工厂明细泄露、子状态绕过、草稿新增停用引用、供应能力、SQL CHECK NULL分支、草稿自有明细删除、树形节点id均已修复并纳入相应验证。

- 镜像源使用AWS Public ECR的Docker Official PostgreSQL17，保持数据库方案；未改宿主DNS/代理或操作其他项目服务。
