# 业务编号中心实施与验收记录

日期：2026-10-24；对应U-016，已上线https://mes.xiaomtech.cn。

编号中心提供“编号规则”和“分配记录”。规则支持公司/固定工厂范围、MO/LOT/SN用途、固定安全格式、周期流水、草稿维护、启停与格式预览；分配记录和号码明细可查询。**生产订单、建批、单件追溯业务尚未接入**，无公开取号/预留/回收HTTP接口，无生成假订单或孤立号码按钮。生产新四表初始为空，由用户建立规则，真实号码只能由未来业务保存事务产生。

## 实现边界

- 004增量表：numbering_rules、numbering_counters、number_allocations、number_allocation_items。技术UUID、既有code、物料SN策略及既有组织数据不迁移。计数使用稳定公司/用途/scope/重置周期/周期值键，不按rule_id重置；最终号码按公司+用途唯一。
- 内部`allocateNumbers(connection,actor,request)`只接受外层已开启事务的Connection，自己不BEGIN/COMMIT。业务入口须先授权并传匹配的内部业务操作授权；仅有规则维护角色不代表有生产业务取号授权。服务器请求时间在整事务重试间保持，幂等指纹不含时间和幂等键；重复已提交请求跨日或停用后仍返回原明细。
- 父公司→工厂→规则FOR SHARE，计数器FOR UPDATE；规则维护和父级状态使用排他锁。命名空间启用独立稳定锁，同空间只能一ACTIVE规则。已首次启用核心字段冻结；新规则接续稳定流水，最终号碰撞409并整体回滚，不循环跳号。
- BigInt运算和字符串JSON流水；MO/LOT单次1个，SN上限1000，溢出整批422；分配头/明细/计数/审计与业务提交同事务。唯一竞争由外层整事务有限重试，不在失败事务局部继续。
- Connection维护运行时事务状态，autocommit、提交/回滚后、release/destroy后拒绝取号；提交开始即失效，活动事务禁止DDL、重复START/BEGIN及SET autocommit。受信内部代码不得绕过raw连接、并发提交和分配或混入隐式提交语句。
- ADMIN/EDITOR/RELEASER/VIEWER及公司+工厂范围按契约；父级失效禁止新写，但历史和有范围的格式预览可读。没有fingerprint或完整业务payload出现在分配查询/审计中。
